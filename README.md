# Биометрическая верификация

Лабораторная работа №5 по дисциплине «Обработка данных в интеллектуальных
и киберфизических системах», 3 курс, 2 семестр.

## Задача
В работе решаются две задачи биометрической верификации.

Первая задача это сравнение отпечатков пальцев. По двум сканам нужно
определить, сняты ли они с одного пальца. Модель должна работать
и для пальцев, которых не было в обучающих данных.

Вторая задача это проверка подлинности подписи. По двум подписям нужно
определить, обе ли они настоящие подписи одного человека или одна
из них подделка.

## Данные
**Отпечатки пальцев.** Собран собственный датасет, около 500 сканов 26 пальцев,
полученных на сканере отпечатков. Модель обучается на 16 пальцах,
а проверяется на 10 других, которых не видела при обучении.

**Подписи.** Датасет [Signature Verification](https://www.kaggle.com/datasets/robinreni/signature-verification-dataset)
с настоящими и поддельными подписями, дополненный собственными подписями
и подделками под них. Разбиение на обучение и тест сделано по людям,
85% и 15%.

Для обучения изображения объединены в пары. Пара считается совпадающей,
если это два скана одного пальца или две настоящие подписи одного человека,
и несовпадающей, если это сканы разных пальцев или настоящая подпись
и подделка.

## Модель
Сиамская свёрточная сеть, которая сравнивает два изображения
и определяет, принадлежат ли они одному человеку.
